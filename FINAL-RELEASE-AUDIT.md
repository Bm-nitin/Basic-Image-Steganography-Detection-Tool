## 4. Production Code Audit

[MEASURED] Reviewed `app/__init__.py`, `app/config.py`, `app/routes.py`, and all 18 files under `app/core/`. One finding, not previously surfaced in G1–G8 (those phases focused on detector correctness, not deployment configuration):

**Finding P1 — in-memory analysis cache is not safe under the project's own documented multi-worker configuration.**
[MEASURED, source-verified from `app/routes.py`] `ANALYSIS_CACHE: Dict[str, Dict[str, Any]] = {}` is a plain Python process-local dictionary. `/analyze` stores a freshly-computed result under a UUID key; a separate, later request to `/download-report/<analysis_id>` looks the key up in the same dictionary. The `Procfile` runs `gunicorn wsgi:app --workers 2` — gunicorn's default sync worker model uses **separate OS processes with independent memory**, so a result stored by worker A is invisible to worker B. If the load balancer routes a user's follow-up PDF-download request to a different worker than the one that handled `/analyze`, the lookup fails.
**Impact:** [SOURCE-VERIFIED from code] the failure path is graceful, not a crash — `download_report` redirects with a "session expired or not found" flash message when the key is missing (`app/routes.py`, lines ~171–180) — so this is not a security or stability defect, but it is a real, reproducible-in-principle functional defect affecting an advertised feature (PDF report download) under the exact deployment configuration the project ships with.
**Severity:** classified MAJOR, not BLOCKER, per Section 11 — see rationale there.

No other production-code defect was found. Upload validation, secure filename handling, allowed-format checking, malformed-input handling, API error handling (distinct JSON vs. HTML error paths, confirmed in `app/__init__.py`), temporary-file handling, PDF generation code paths, and deterministic scoring (confirmed via the freshness spot-checks performed in G6/G7/G8, all exact-match reproductions) are all present and functioning as documented.

## 6. Tampering Independence

[SOURCE-VERIFIED, re-confirmed directly from `app/core/scoring.py`] `tampering_score` is computed entirely separately from the steganography `score` accumulator: `score` only ever receives `structural_pts`, `sig_pts` (metadata), `total_stat_pts` (statistical), and `vis_pts` (visual) — `tampering_score` is computed independently (`tampering_score = float(tampering_res.get('combined_score', 0.0))`) and is only written into the final result dictionary, **never added into `score`**. ELA, noise, local variance, edge, and copy-move all remain distinct sub-detectors feeding only `tampering_score`. Tampering does not silently add points to the steganography score — confirmed by direct source inspection, not inferred from behavior alone.

## 10. Known Limitations

Carried forward, verbatim in substance, from G2–G8, now also reflected in `README.md` §14 per Section 9:

- Natural photographs — real or synthetic, high-texture or smooth, without exception in the evaluated corpus — can produce Medium-risk suspicion scores from LSB entropy and visual-balance alone, with no embedded payload. [MEASURED, G7/G8]
- Low-payload steganographic content shows markedly reduced detection rates relative to medium/high payload across every evaluated carrier class. [MEASURED, G2–G7]
- No independent, held-out validation set exists; all reported metrics describe the project's own controlled/synthetic 92-sample evaluation corpus. [MEASURED, G3, reconfirmed G7]
- LSB entropy and visual-balance are highly correlated and largely decision-level redundant (G5/G6); Chi-Square and RS also correlate moderately (G6) but retain independent decision-level value; no scoring change has been made to act on this, by design.
- The RS `sym_diff` term is a source-verified applicability diagnostic, correctly separated (G4) from embedding evidence; Chi-Square's whole-image application is a source-verified but imperfect match to this project's random-subset embedding model (G5).
- Copy-move detection has a known, source-verified grid-alignment sensitivity for non-stride-aligned forgery displacements, and a separate, distinct significance-floor limitation for small multi-region forgeries (G4).

None of these are release blockers; all are accurately reflected as known, disclosed limitations rather than silent gaps.
